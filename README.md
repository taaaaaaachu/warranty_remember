# Warranty Remember(保証リマインダー)

ガジェットなどの保証書・保証終了日・購入情報・問い合わせ先を、画像付きで**世帯単位**にまとめて管理する Web アプリ(PWA)。「保証書がどこにあるか分からない」「保証が切れているか分からない」を解消するためのもので、家族や小規模グループでの利用を想定しています。

ドメインの用語は [CONTEXT.md](./CONTEXT.md)、主要な設計判断は [docs/adr/](./docs/adr/) を参照してください。

## 主な機能

- **保証登録の管理**: ガジェット名・カテゴリ・メーカー・型番・シリアル番号・購入日・購入店・金額・問い合わせ先メモ・自由メモを1件の保証登録として記録。
- **保証終了日の自動計算**: 保証期間(月数)を入れると購入日から保証終了日を算出。延長保証などで保証終了日を手動で上書きすると保証期間は未設定に戻り、矛盾した値を残さない。
- **期限の見える化**: 一覧は保証終了日が近い順に並び、「あと◯日 / 本日 / ◯日超過」をバッジで表示(30日以内・期限切れは色を変えて強調)。
- **検索・絞り込み**: 名前・メーカー・型番・シリアル番号での検索と、カテゴリでの絞り込み。
- **添付画像**: 保証書・レシート・本体・シリアル部分などの画像を1件に複数枚添付。サーバー側でリサイズ・JPEG 圧縮してから保存。
- **アーカイブ**: 保証切れや手放したものを通常一覧から外して履歴画面へ。削除ではなく、いつでも復元できる。
- **世帯と共有**: 保証登録はユーザー個人ではなく世帯が所有。1人が複数世帯に所属して切り替え可能。世帯内ロール(`owner` / `manager` / `member`)、manager の任命・解任、メンバー除名、owner 交代(相手の承諾制)、脱退に対応。
- **招待制**: 最初の1人(インスタンス管理者)以外は招待コードがないと登録できない。招待コードは有効期限付き・単回使用で、無効化もできる。
- **パスキー認証**: ユーザー名入力なしでログインできるパスキーに対応。パスワードなし(パスキーのみ)での登録や、パスワードを削除してパスキー専用にすることも可能。
- **インスタンス管理**: インスタンス管理者による世帯・ユーザーの管理、パスワードリセット。
- **PWA**: Web App Manifest と Service Worker によりホーム画面へインストール可能(オフライン時は固定のオフラインページを表示)。

## 技術スタック

| 区分 | 採用技術 |
|---|---|
| フロントエンド / サーバー | SvelteKit 2(Svelte 5 runes モード)+ TypeScript 6、adapter-node によるフルスタック1本構成 |
| DB | SQLite(better-sqlite3)+ Drizzle ORM / drizzle-kit によるマイグレーション |
| 認証 | サーバーセッション(httpOnly Cookie)、パスワードは Argon2(`@node-rs/argon2`)、パスキーは SimpleWebAuthn(`@simplewebauthn/server` / `browser` v14) |
| 画像処理・ストレージ | sharp でリサイズ・圧縮し、ローカルファイルシステムに保存 |
| PWA | Web App Manifest + Service Worker |
| インフラ | Docker(マルチステージビルド、Node.js 22)、GHCR、Watchtower による自動更新、Cloudflare Tunnel 経由で公開 |
| CI/CD | GitHub Actions(ESLint・svelte-check・Vitest → main のみイメージをビルドして GHCR へ push) |
| テスト | Vitest 4 |

## アーキテクチャと設計判断

```
ブラウザ(PWA)
   │  HTTPS(Cloudflare Tunnel)
   ▼
SvelteKit(adapter-node / Node.js 22, Docker コンテナ)
   ├─ hooks.server.ts … セッション検証・強制パスワード変更の制御・現在の世帯の解決
   ├─ routes/api/*    … 保証登録・添付画像・世帯・招待・認証情報の API
   └─ lib/server/*    … ドメインロジック(すべての保証登録操作は世帯IDで絞り込む)
        │
        ├─ SQLite(/data/app.sqlite)… 保証登録・世帯・ユーザー・セッション等
        └─ ファイルシステム(/data/uploads)… 添付画像(DB にはパスのみ)
```

- **単一プロセス・単一ボリューム**: アプリ・DB・画像を1コンテナと1つの `/data` ボリュームに収め、バックアップは `data/` ディレクトリのコピーで完結する。
- **権限判定は純粋関数に分離**: `src/lib/rbac.ts` は DB に依存しない判定関数だけを持ち、API 側は `requireUser` / `requireHousehold` / `requireRecentAuth` / `requireInstanceAdmin`(`src/lib/server/apiGuard.ts`)を通して認可する。
- **保証終了日は単一の正**: 保証期間(月数)は入力補助値にすぎず、保証終了日を手動で上書きした時点で破棄する(`src/lib/domain/warrantyEntry.ts`)。
- **マイグレーションの安全策**: drizzle-kit が生成するテーブル作り直し型のマイグレーションはトランザクション内で走るため、SQL 中の `PRAGMA foreign_keys=OFF` が効かず、`ON DELETE CASCADE` で関連データが消えうる。`scripts/migrate.js` では適用前に外部キーを無効化し、適用後に `foreign_key_check` で違反がないことを確かめてから有効に戻す。コンテナ起動時に自動適用する。

### ADR(Architecture Decision Records)

| ADR | 要約 |
|---|---|
| [0001 添付画像はサーバーのローカルファイルシステムに保存する](./docs/adr/0001-local-filesystem-image-storage.md) | DB への BLOB 格納や S3 互換ストレージと比較し、サーバー1台・Docker ボリューム運用という前提から、DB 肥大化を避けつつ追加インフラなしで済むローカル保存を選択。複数サーバー化する際はファイル移行が必要になる、というコストも明記。 |
| [0002 パスキーのみのユーザーを認め、復旧は管理者リセットで認証情報を全初期化する](./docs/adr/0002-passkey-only-users.md) | パスワード「無効化フラグ」ではなく削除にして漏えいした旧パスワードの復活を防ぐ。招待制の小規模運用なのでメール復旧は持たず、復旧窓口を管理者リセットに一本化。リセット時は乗っ取られた可能性のあるパスキーも全削除する。 |
| [0003 管理者リセットの仮パスワードはパスキー登録でも解除でき、パスワードを決めないリセットリンクも用意する](./docs/adr/0003-temporary-password-and-reset-link.md) | 仮パスワードの本人は、新しいパスワードかパスキーを設定するまで他の操作ができない。パスワードを決めないリセットリンク(24 時間・単回)も用意し、認証情報の初期化は発行時でなく使った時点で行う。自分自身はどちらの対象にもできない。 |

## セキュリティ上の工夫

- **パスキー(WebAuthn)**: discoverable credential によるユーザー名なしログイン。ユーザー検証(`userVerification: 'required'`)を要求。RP ID はリクエストのホスト名から決定。
- **パスワードは Argon2 でハッシュ化**(OWASP 推奨相当のパラメータ)。ユーザーが存在しない・パスワードを持たない場合もダミーのハッシュ計算を行い、応答時間からアカウントの有無を推測されにくくしている。
- **セッショントークンはハッシュで保存**: Cookie に入れる平文トークンは DB に残さず、SHA-256 ハッシュのみを保存。Cookie は `httpOnly` / `SameSite=Lax` / 本番では `Secure`。有効期限30日で、残り15日を切ると自動延長。
- **認証試行制限**: ログイン・パスワード変更・本人確認・アカウント削除のパスワード検証に共通で適用。ユーザー単位は15分間に5回、IP 単位は15分間に20回の失敗で15分間拒否(DB に記録するキーもハッシュ化)。
- **本人確認(再認証)**: 認証情報の追加・削除やアカウント削除は直近5分以内の本人確認を要求。認証情報を減らす操作では、操作した端末以外のセッションを無効化する。認証情報が0になる操作はサーバー側で拒否。
- **招待制**: 最初の1人以外は、有効期限付き・単回使用の招待コードがないと登録できない。
- **強制パスワード変更**: 管理者リセット後のユーザーは、パスワード変更とログアウト以外のページ・API に到達できない(`hooks.server.ts` で一律に制御)。リセット時は全パスキー・全セッションも削除する。
- **世帯によるデータ分離**: 保証登録・添付画像の取得はすべて現在の世帯 ID で絞り込み、他世帯のデータには 404 を返す。
- **アップロード画像の扱い**: 1枚20MB までかつ `image/*` のみ受け付け、sharp で再エンコード(EXIF の向きを反映したうえで最大1920px・JPEG に正規化)してから保存。保存パスはサーバー生成の ID とランダムなファイル名だけで組み立て、ユーザー入力のファイル名は使わない。配信時は世帯の所有権を確認してから返す。
- **Service Worker はオフラインページのみキャッシュ**: 認証済み画面・API レスポンス・添付画像はキャッシュしない。

## テスト

- **Vitest** によるテスト: **16ファイル / 110件**(`npm test` で全件パス)。
- 主な対象:
  - 保証終了日の計算・並び替え、入力値の検証、表示フォーマット
  - 世帯・所属・招待コード・owner 交代などの世帯ロジック、RBAC の権限判定、API ガード
  - 認証(セッション、パスワード、認証情報の追加・削除、認証試行制限)
  - WebAuthn: テスト内のソフトウェア認証器(ES256)で登録 → ログインの往復を検証
  - 添付画像の保存処理、マイグレーション適用時に既存データが消えないこと、PWA マニフェストと Service Worker の構成
- **CI**: GitHub Actions(`.github/workflows/ci.yml`)で push(main)と全 PR に対し、ESLint → svelte-check(型チェック)→ Vitest を実行。

## ローカルでの起動方法

Node.js 22 を想定(CI・Docker イメージと同じ)。

```bash
npm ci
cp .env.example .env   # 任意。既定値は ./data/app.sqlite と ./data/uploads
npm run db:migrate     # SQLite にスキーマを適用(./data/app.sqlite)
npm run dev            # http://localhost:5173
```

ブラウザで `/register` を開くと、最初のユーザーは招待コードなしで登録でき、インスタンス管理者になります。

その他のスクリプト:

| コマンド | 内容 |
|---|---|
| `npm test` | テスト実行 |
| `npm run check` | 型チェック(svelte-check) |
| `npm run lint` | ESLint |
| `npm run db:generate` | スキーマ変更後にマイグレーションを生成(その後 `npm run db:migrate`) |
| `npm run build` / `npm start` | 本番ビルドと起動 |

Docker で本番同等の構成を手元で確認する場合:

```bash
docker compose -f docker-compose.local.yml up --build   # http://localhost:3000
```

## デプロイ

プル型の CI/CD で運用しています。`main` に push すると GitHub Actions がテスト後に Docker イメージをビルドして GHCR に push し、サーバー側の Watchtower が新しいイメージを検知して自動で pull・再作成します。コンテナは起動時に DB マイグレーションを適用し、外部公開は Cloudflare Tunnel 経由(ポート開放なし)です。

```
push / PR ─▶ GitHub Actions(lint / check / test)
     main ─▶ Docker ビルド ─▶ GHCR(:latest, :sha-xxxxxxx)
                                └─▶ Watchtower が自動 pull ─▶ 再作成(起動時にマイグレーション)
```

手順とトラブルシューティングは [DEPLOY.md](./DEPLOY.md) を参照してください。
